# 行情性能测试脚本

行情接口按使用方式分为两类：

| 类别 | 含义 | 适合的测试时间 |
| --- | --- | --- |
| 快照 | 每次调用返回一份行情或历史数据 | 历史数据可在任意时间测试；最新行情在非交易日只代表最近快照 |
| 实时 | 建立订阅后持续接收新增数据 | 必须在对应市场的交易时段测试 |

当前公开脚本先覆盖快照接口。它生成 JSON 测试记录和 Markdown 报告，Markdown 为每个接口分别生成一张结果表，不计算名次，也不输出“领先”或“落后”等结论。每张表优先展示可用性、成功率、返回完整性和 P95 慢请求耗时。

## 快照测试项

| 测试项 | 默认样本 |
| --- | --- |
| 指定证券行情快照 | 3 只 A 股 |
| A 股全市场快照 | 沪深京全市场 |
| 历史日 K | 首只证券近一年 |
| 历史 1 分钟 K / 分时 | 首只证券最近完整交易日 |
| 普通成交明细 | 首只证券最近完整交易日 |
| 五档盘口快照 | 3 只 A 股 |
| Level-2 逐笔成交 | 首只证券最近完整交易日 |
| Level-2 逐笔委托 | 首只证券最近完整交易日 |
| Level-2 买入撤单 | 首只证券最近完整交易日 |
| Level-2 卖出撤单 | 首只证券最近完整交易日 |

测试项不会因为某个项目暂不支持而从清单中删除。报告会分别标记完成、不支持、需要权限、返回不完整、失败或不可用。

## 对比项目

默认包含 FQGate、AKShare、easyquotation、mootdx 和 Tushare。不同项目的数据源、授权要求和批量能力可能不同，JSON 报告会保留项目版本、准备耗时、返回行数和每次测试调用项目公开方法的次数；供人阅读的 Markdown 表格只优先展示判断接口表现所需的数据。

## 准备环境

安装 Python 3.11 或更高版本，启动 FQGate，然后在仓库根目录创建独立环境。

Windows PowerShell：

```powershell
python -m venv .venv-benchmark
.\.venv-benchmark\Scripts\python.exe -m pip install -r scripts\market_benchmark_requirements.txt
```

macOS：

```bash
python3 -m venv .venv-benchmark
./.venv-benchmark/bin/python -m pip install -r scripts/market_benchmark_requirements.txt
```

第三方项目可能访问东方财富、腾讯、新浪或通达信的公开行情服务。运行前请自行确认相应项目和数据源的使用条款，并保持合理的调用频率。

## 运行快照测试

默认使用三只沪市股票、2 轮预热和 10 轮正式测试：

```powershell
.\.venv-benchmark\Scripts\python.exe scripts\benchmark_market_snapshots.py
```

macOS 使用：

```bash
./.venv-benchmark/bin/python scripts/benchmark_market_snapshots.py
```

脚本默认通过 FQGate 交易日历选择今天以前最近的完整交易日。也可以明确指定日期、测试项和轮数：

```powershell
.\.venv-benchmark\Scripts\python.exe scripts\benchmark_market_snapshots.py `
  --trade-date 20260911 `
  --scenarios selected_quote,daily_kline,minute_kline,trade_details,depth_l1 `
  --rounds 10 `
  --output benchmark-results\market-snapshots.json
```

查看全部测试项：

```powershell
.\.venv-benchmark\Scripts\python.exe scripts\benchmark_market_snapshots.py --list-scenarios
```

基准测试会自动调用报告生成器。调整展示规则后，也可以直接从已有 JSON 测试记录重新生成 Markdown，不需要重新测试或手工修改表格：

```powershell
.\.venv-benchmark\Scripts\python.exe scripts\generate_market_benchmark_report.py `
  benchmark-results\market-snapshots.json
```

正常返回的数据只记录耗时、行数和完整性，不保存价格、成交量等行情原值。JSON 测试记录保留脱敏后的原始异常，Markdown 的错误列只展示错误类型和发生次数，不展示具体响应；所有项目的软件版本在报告开头统一列出。账号、Token、Cookie、密码和认证头等凭据始终脱敏。`benchmark-results/` 默认不进入 Git；公开结果前应人工核对测试日期、项目版本和状态。
